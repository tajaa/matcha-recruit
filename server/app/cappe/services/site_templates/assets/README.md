# Store starter sample photography

These bundled images are illustrative merchandise in the private storefront and
template-gallery previews. They are never inserted into a catalog, saved in page
content, or rendered on a public site. The versioned, allowlisted
`GET /api/cappe/templates/starter-media/{key}` endpoint serves WebP with a one-day
cache. The three 960px assets total about 172 KB. Original generations remain in
the Codex image library; these files are resized and encoded for delivery.

Generated with the built-in imagegen tool. Exact prompts follow.

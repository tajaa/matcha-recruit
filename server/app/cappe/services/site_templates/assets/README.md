# Store starter sample photography

These bundled images illustrate private storefront, template-gallery and writers'
Studio template previews. They are never inserted into a catalog or magazine library,
saved in page content, or rendered as sample imagery on a public site. The versioned, allowlisted
`GET /api/cappe/templates/starter-media/{key}` endpoint serves WebP with a one-day
cache. The three 960px product assets total about 172 KB. The four editorial assets, up to 750×1000,
assets each stay below 100 KB. Original generations remain in
the Codex image library; these files are resized and encoded for delivery.

Generated with the built-in imagegen tool. Exact prompts follow.

# Scheduling landing page

`/` is the scheduling home page, with setup/integrations, staffing recovery examples, operational fit, a value estimator, proposed pricing, and practical FAQs alongside the scheduling demonstrations. `/scheduling-v2` redirects to `/`, preserving query parameters and section links. The home page uses the canonical root URL and is indexable; `/incidents` retains its existing content.

The $49 Basic / $99 Pro / $149 Autopilot prices and inclusions are proposals. This change does not create subscriptions, grant product features, or change billing. Plan CTAs open the existing consultation form. The current self-serve signup remains the same destination.

Square finalized sales and CSV imports are described precisely. No native Toast, time clock, actual-break verification, payroll export, or automatically bundled HR/incident capabilities are promised. First-account roster import and later pay-rate import are distinguished.

The value calculator uses a shared current-week baseline and independent assumptions for Basic, Pro, and Autopilot. Blank remaining-time fields assume no time saved. Basic retains labor-cost-review work and cannot claim savings from that unavailable feature. Prices come from the same plan definitions as the pricing section.

Manager capacity and cash are separate. Optional paid-labor savings default to zero: removed regular hours use the regular hourly cost, while overtime moved to regular pay saves only the premium. These hours must not overlap or include manager time. Software savings require an explicit cancellation assumption per plan. Recurring time, cash, and subscription amounts scale with locations. The business's one-time switching spend reduces both first-year totals; internal manager onboarding time reduces value only, at the entered hourly value. Neither one-time input scales with location count. Weekly work converts to monthly with 52 / 12. Negative outcomes remain visible, and invalid or incomplete inputs suppress estimates.

Visible instructions, field explanations, a monthly calculation breakdown, and an editable café example explain how to use the comparison. Example time estimates are illustrative assumptions, not measured results. Volume discounts, taxes, growth, and speculative compliance savings are excluded. No customer results, logos, testimonials, or screenshots are invented.
